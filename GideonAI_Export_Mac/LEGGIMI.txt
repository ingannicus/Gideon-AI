=== WINDOWS — PRIMA INSTALLAZIONE ===

1. Doppio clic su  →  start.bat
   Verifica Ollama, lo avvia, scarica i modelli e lancia l'app.

2. Se Ollama non è installato:
   → Scaricalo da https://ollama.com/download
   → Installalo, poi riavvia start.bat

3. Al primo avvio scarica i modelli AI (circa 8GB totali).
   Ci vuole tempo, lascialo lavorare.

4. Il browser si aprirà su:  http://localhost:5000


=== WINDOWS — AVVII SUCCESSIVI ===

Doppio clic su  →  Gideon AI.exe
Oppure usa la shortcut  →  Avvia Gideon AI.lnk


=== MAC — PRIMA INSTALLAZIONE ===

1. Installa Ollama da https://ollama.com/download

2. Apri il Terminale e rendi eseguibile lo script:
      chmod +x start.sh

3. Doppio clic su  →  Avvia Gideon AI.command
   Oppure dal Terminale:  ./start.sh

4. Al primo avvio scarica i modelli (circa 8GB totali).

5. Il browser si aprirà su:  http://localhost:5000


=== MAC — AVVII SUCCESSIVI ===

Doppio clic su  →  Avvia Gideon AI.command
Oppure dal Terminale:  ./gideon-ai


=== MODELLI USATI ===

  • gemma3:4b              → Conversazione generale e sicurezza
  • qwen2.5-coder:3b       → Generazione e analisi codice
  • dolphin llama3.2-3b    → Modalità uncensored


=== REQUISITI MINIMI ===

  • RAM:   8GB (consigliati 16GB)
  • Disco: 10GB liberi per i modelli
  • CPU:   qualsiasi moderna (con GPU è molto più veloce)
  • OS:    Windows 10/11 oppure macOS 12+


=== NOTE ===

  • Tutto gira localmente sul tuo PC. Zero cloud, zero API key.
  • Nessun dato viene inviato a server esterni.
  • Porta usata: 5000 (solo locale).
  • Per fermare: chiudi la finestra del terminale.
